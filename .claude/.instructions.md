# AIOX Agents Configuration

Este arquivo ativa os agentes AIOX no Claude Code.

## Agentes Disponíveis

- `@architect` - Arquitetura e design técnico
- `@dev` - Implementação de código
- `@qa` - Testes e qualidade
- `@pm` - Product Management
- `@po` - Product Owner / Stories
- `@sm` - Scrum Master
- `@analyst` - Pesquisa e análise
- `@data-engineer` - Design de banco de dados
- `@ux-design-expert` - UX/UI design
- `@devops` - DevOps / CI-CD
- `@aiox-master` - Orquestrador master

## Como usar

Use `@agent-name` no chat para ativar o agente desejado.
